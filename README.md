# Car-Racing-Game
🏎️ Car Racing Game

An exciting 2D arcade-style Car Racing game built using Python. Avoid incoming traffic, navigate through challenging obstacles, collect power-ups, and aim for the highest score!

✨ Features

🚘 Smooth Player Controls: Responsive movement handling (Keyboard Arrow keys / WASD).

🛣️ Dynamic Traffic & Obstacles: Randomly spawning enemy cars and obstacles with increasing speed.

💥 Collision Detection: Precise hitboxes for vehicle crashes and game-over triggers.

🏆 Score System: Real-time distance/score tracker with high score recording.

🎨 Retro Visuals & Sound: Engaging 2D graphics, road animations, and audio effects.

🛠️ Built With

Python 3.x - Game logic and application state handling.

Pygame - 2D graphics rendering, sound synthesis, and event listening.

🚀 Getting Started

Prerequisites

Make sure you have Python 3.x installed. Install the necessary dependencies (e.g., Pygame) by running:

pip install pygame


Installation & Execution

Clone the repository:

git clone https://github.com/YOUR-USERNAME/Car-Racing-Game.git
cd Car-Racing-Game


Run the Game:

python main.py


(Replace main.py with your Python entry script name if it is different).

🕹️ Controls

Left Arrow / A: Move car left

Right Arrow / D: Move car right

Up Arrow / W: Accelerate / Increase speed

Down Arrow / S: Brake / Slow down

Spacebar / P: Pause / Resume game
